# Aimbot

Versão 1.0.0 · pacote com.aimbot.app

## Estrutura

- `app/src/main/AndroidManifest.xml` — declara o app e as permissões pedidas.
- `app/build.gradle` — versão e identificador do aplicativo.
- `app/src/main/java/com/aimbot/app/MainActivity.java` — tela principal.
- `app/src/main/res/values/strings.xml` — nome exibido no aparelho.

Compile com `gradle assembleDebug` (Android SDK 34 e JDK 17).
